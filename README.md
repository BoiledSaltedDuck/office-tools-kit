> **Office Tools Kit 系列** — 用AI写代码，用工具提效。一行命令搞定日常办公与开发杂务。

## 安装

```bash
pip install office-tools-kit
```

## 工具列表

### 1. excel-merge — Excel文件批量合并

合并多个Excel文件为一个，支持 .xlsx 和 .xls 格式。

```bash
excel-merge ./数据/ 合并结果.xlsx
```

### 2. excel-split — Excel文件按列拆分

按指定列的值，将一个Excel拆分成多个文件。

```bash
excel-split 数据.xlsx 部门
```

### 3. pdf-merge — PDF文件合并

合并多个PDF文件为一个。

```bash
pdf-merge ./pdf文件/ 合并结果.pdf
```

## 特点

- 零配置，安装即用
- 支持批量处理
- 自动处理编码和格式问题
- 兼容 Windows/Linux/Mac
